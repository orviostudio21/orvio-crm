# Direção visual

Editorial greeting: A personal or team home that opens with a typeset greeting in a centred column; every number below it is set at regular weight on tonal panels.

Fonte Instrument Sans servida localmente, contraste legível, navegação móvel recolhível e foco visível. As métricas e gráficos derivam dos registros; não há números promocionais fixos. A marca orbital representa a continuidade do trabalho.

Amostras são fictícias e adicionadas somente quando o usuário solicita em um espaço vazio.
